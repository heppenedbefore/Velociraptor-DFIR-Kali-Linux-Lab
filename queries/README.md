# VQL examples

These are **safe read-only examples** documented from the laboratory's verified concepts. The `read_saved_vfs_listing.vql` pattern mirrors the successfully executed notebook read, but the public copy deliberately replaces actual Client and Flow IDs with placeholders. The `local_system_info.vql` is a minimal illustrative query; it is not asserted as a separate verified server flow.

Run queries in the proper Velociraptor context, with appropriate permissions and on authorized infrastructure. `flow_results()` is server-side and requires permission to read results. The notebook smoke test does not inspect an endpoint.
